# Wedding Game

一款用于电子婚礼请柬的竖屏轻量互动小游戏。

玩家以“勇士”的身份协助王子寻找公主，穿越森林、跨越障碍、击败哨兵，并从宝箱中选择一件宝物。抵达城堡后，玩家发现所谓的怪物其实是新人养的猫。故事最后由勇士为王子与公主拍照，照片转化为婚礼迎宾海报，并进入正式请柬。

## 文档入口

- [完整故事稿](docs/story.md)：当前故事的唯一正文来源。
- [设定与决策记录](docs/decisions.md)：已确认约束、三条宝物分支和待补充信息。

## 内容维护规则

1. 剧情调整优先修改 `docs/story.md`。
2. 已确认的关键设定同步记录到 `docs/decisions.md`。
3. 后续分镜、交互、视觉和程序实现均以故事正文为准，不直接改写核心设定。
4. 新人姓名、婚礼日期和地点仍可在 `game.js` 的 `GAME_CONFIG` 中替换；将迎宾照命名为 `welcome-photo.png` 放在项目根目录即可接入。

## 迎宾照

- 迎宾照：将照片放到项目根目录并命名为 `welcome-photo.png`。照片会自动按屏幕比例完整适配；如果暂时没有照片，海报继续显示像素画兜底。
- 页面每次加载都会为照片请求追加时间戳，替换图片后重新打开页面即可看到新版本。
- 如需使用其他文件名，直接修改 `game.js` 中 `GAME_CONFIG.welcomePhoto` 的路径。
