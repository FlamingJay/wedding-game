# 背景音乐

请将两首背景音乐放在当前目录，并分别命名为：

```text
game.mp3
ending.mp3
```

完整路径及用途：

```text
frontend/assets/music/game.mp3     # 游戏开始至通关前播放
frontend/assets/music/ending.mp3   # 进入婚礼海报后播放
```

两首音乐都会自动循环播放。游戏进入婚礼海报时会自动从 `game.mp3` 切换到 `ending.mp3`；通过“跳过游戏”直接进入海报时也会切换。如果浏览器禁止自动播放，用户第一次点击、触摸或按键后会自动开始播放。页面中不会显示音乐开关按钮。

建议：

- 使用 MP3 格式
- 建议文件大小控制在 `5MB` 以内
- 建议音乐时长在 `1–5` 分钟之间
- 建议导出为 `96–160kbps`，兼顾音质和移动端加载速度
