# 首版交互流程

## 状态列表

| 状态 | 画面 | 玩家操作 | 完成条件 |
|---|---|---|---|
| `title` | 游戏标题与开始按钮 | 点击开始 | 进入任务对白 |
| `briefing` | 王国紧急委托 | 点击继续 | 进入森林 |
| `forest` | 王子与勇士自动前进 | 点击屏幕跳跃 | 越过一个障碍 |
| `guard` | 哨兵挡路 | 点击攻击三次 | 哨兵退场 |
| `treasure` | 宝箱和三个宝物 | 点击选择一项 | 保存选择并前往城堡 |
| `castle` | 巨大怪物出现 | 点击拔剑 | 公主阻止战斗 |
| `branch` | 所选宝物的猫咪反应 | 点击继续 | 进入身份揭晓 |
| `reveal` | 怪物缩小为猫咪 | 点击继续 | 进入王子与公主对白 |
| `couple` | 两人决定一起出发 | 点击继续 | 进入拍照场景 |
| `photo` | 相机取景框 | 点击快门 | 闪白并生成迎宾海报 |
| `poster` | 婚礼迎宾海报 | 重玩或查看分享提示 | 流程结束 |

## 输入规则

- 全程以单击或触摸为主，不依赖复杂方向控制。
- 每个场景只有一个主要动作；宝箱场景例外，提供三个并列选择。
- 不设置失败结束。森林跳跃失误后短暂停顿并自动恢复。
- 防止快速连点跨过场景；场景切换期间暂时锁定输入。
- 页面隐藏后暂停动画，回到页面时恢复当前状态。

## 首版验收条件

- 在 375×667、390×844、430×932 三种竖屏尺寸下不溢出。
- 从开始到迎宾海报的完整流程可点击通过。
- 三种宝物都能进入正确分支并回到共同结局。
- 刷新页面后可以重新开始，不依赖后端。
- 控制台没有 JavaScript 错误。
- 页面在 HTTPS 静态托管后可通过微信内置浏览器打开。
