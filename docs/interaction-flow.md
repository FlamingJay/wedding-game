# 首版交互流程

## 状态列表

| 状态 | 画面 | 玩家操作 | 完成条件 |
|---|---|---|---|
| `title` | 游戏标题与开始按钮 | 点击开始 | 进入任务对白 |
| `briefing` | 皇家信使发布委托 | 接受任务并登记勇士名字 | 进入森林 |
| `forest` | 王子与勇士结伴前进 | 左右移动、跳跃、收集光点 | 越过木桩并抵达森林出口 |
| `guard` | 森林哨兵巡逻挡路 | 移动、跳跃、靠近后攻击 | 三次命中并完成终结技 |
| `treasure` | 宝箱和三个宝物 | 点击选择一项 | 保存选择并前往城堡 |
| `castle` | 巨大怪物出现 | 移动、跳跃、点击拔剑 | 公主阻止战斗并询问礼物 |
| `branch` | 大怪物对所选宝物作出反应 | 点击“看看它是谁” | 进入身份揭晓 |
| `reveal` | 怪物缩小为猫咪 | 点击继续 | 进入王子与公主对白 |
| `couple` | 两人决定一起出发 | 点击继续 | 进入拍照场景 |
| `photo` | 相机取景框 | 点击快门 | 闪白并生成迎宾海报 |
| `poster` | 婚礼迎宾海报 | 重玩或查看分享提示 | 流程结束 |

## 输入规则

- 森林和城堡支持触控方向键，也支持键盘方向键或 `A/D` 移动。
- `W`、方向上键或空格跳跃；森林哨兵战中使用【击】或 `J/K` 攻击。
- 哨兵战之后不再显示【击】，城堡只通过剧情按钮触发拔剑动作。
- 不设置失败结束；障碍和哨兵碰撞只会阻挡或击退队伍。
- 防止快速连点跨过场景；场景切换期间暂时锁定输入。
- 页面隐藏后暂停动画，回到页面时恢复当前状态。

## 首版验收条件

- 在 375×667、390×844、430×932 三种竖屏尺寸下不溢出。
- 从开始到迎宾海报的完整流程可点击通过。
- 三种宝物都能进入正确分支并回到共同结局。
- 刷新页面后可以重新开始，不依赖后端。
- 控制台没有 JavaScript 错误。
- 页面在 HTTPS 静态托管后可通过微信内置浏览器打开。
