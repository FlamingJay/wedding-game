# 设定与决策记录

更新日期：2026-09-14

## 已确认设定

- 玩家身份是协助王子的勇士，不是王子本人。
- 主线顺序为：接受任务 → 穿越森林 → 跨越障碍 → 击败哨兵 → 打开宝箱 → 三选一 → 抵达城堡 → 怪物身份反转 → 拍照 → 迎宾海报。
- 宝箱中只有三件物品：猫罐头、猫粮、鸡蛋。
- 怪物没有伤害公主，也不是真的想与王子和勇士战斗。
- 怪物的真实身份是新人养的猫。
- 猫罐头分支：猫咪停止捣乱，并答应负责婚礼烟花。
- 猫粮分支：猫咪被猫粮吸引，答应乖乖回家、不再捣乱。
- 鸡蛋分支：猫咪只是在玩鸡蛋，不承担其他任务，也不产生额外奖励。
- 婚戒不作为故事中的任务目标或分支道具。
- 猫咪不会出现在现实婚礼现场。
- 最终照片中只有王子和公主，不存在“三人合照”。
- 最终由勇士按下快门，照片转化为正式婚礼迎宾海报。

## 叙事原则

- 前半段认真讲冒险，不能提前泄露怪物就是猫。
- 喜剧反转来自“可怕怪物”和“家养猫咪”的身份落差。
- 三个宝物选择只改变城堡中的局部表现，不改变故事主结局。
- 勇士始终有实际作用：协助闯关、带来宝物，并完成最后的拍照任务。
- 结尾从童话世界自然过渡到真实婚礼，不额外增加与主线无关的互动。

## 已确认视觉与交互约束

- 项目采用适配手机的 9:16 竖版画面。
- 整体使用红白机时代的原创 8-bit 像素美术与声音语言，不复制具体经典游戏的角色、地图、标志或音乐。
- 不设置常驻状态栏或 HUD，不显示生命值、关卡编号、分数、时间、道具栏等长期信息。
- 游戏信息只在需要时短暂出现，例如对话框、操作提示、宝物选择和拍照按钮；完成操作后自动隐藏。
- 互动保持轻量，不设置真正的 Game Over，不要求宾客理解复杂游戏规则。
